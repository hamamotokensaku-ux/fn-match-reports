試合レポートの使い方

大会のリプレイから、1試合の全選手の「動き・撃ち合い・ストーム」をまとめたページです。試合レポート一覧へ戻る

はじめに
  • PC のブラウザで開いてください。マップの印にマウスを乗せる操作と、ドラッグでの地図の移動は、スマホでは使えません。
  • レポートには、その試合の全選手のデータが入っています。自分以外の選手（上位の選手など）も見られます。

各部分の詳しい説明は下にあります。

1全体の評価表

試合に出た全選手が1行ずつ並んでいます。列の見出しをクリックすると並べ替え（もう一度で逆順）、行をクリックするとその選手の詳細が下に出ます。

撃破時刻倒されたリプレイ時刻。最後まで残った選手は「最後まで生存」。
生存時間バスが出発してから倒されるまでの時間。
キル / 撃破した相手倒した人数と、自分を倒した選手。「撃破者不明（ストーム等）」はストームなど、プレイヤー以外で倒れた場合です。
与ダメ / 被ダメプレイヤーに与えた・プレイヤーから受けたダメージの合計。NPC・建築物へのダメージは含みません。

選手の詳細

2選手の選択

ここからも選手を切り替えられます（評価表の行をクリックしても同じ）。

3成績

その選手の撃破時刻・生存時間・キル・与ダメ・被ダメ・サージ・ストームダメージなどです。

6マップ

  • 線＝移動ルート。色で時間帯が分かります：安地の待機中暖色（黄→赤）、安地の収縮中寒色（青→緑）。後半のフェーズほど濃い色です。
  • 円＝安地。
  • ● 与えたダメージの地点　● 受けたダメージの地点　★ キル　✕ 倒された地点　◎ スライダーの時刻にいた位置

8印にマウスを乗せる

●★✕ にマウスを乗せると、時刻・相手・ダメージ量・その時点のサージが出ます。印が重なっているときは、まとめて時刻順に表示されます。

7拡大・縮小

マップ右上の ＋ / － で拡大・縮小、全体で元に戻します。拡大中はドラッグで地図を動かせます。

4表示する区間

試合の一部だけを表示します。

  • 全体：試合を通したルート。
  • バス〜降下：バスから降りて、最初の安地が出るまで。
  • Phase n 待機：n番目の安地が出てから、縮み始めるまで。
  • Phase n 収縮：安地が縮んでいる間。このときは次の安地も点線で出るので、次にどこへ動くべきだったかも分かります。

区間を選ぶと、その区間のルート・印・出来事だけが表示され、スライダーは区間の最初に移動します。

5時間スライダー

動かすと、その時刻にいた位置がマップに ◎ で出て、その時点までの与ダメ・被ダメ・サージが下に表示されます。

9出来事

撃ち合い・キル・倒された・ストームに入った を時刻順に並べています。撃ち合いは、同じ相手との10秒以内のやり取りを1行にまとめています（例：「〜06:42 vs ○○　与ダメ 209 / 被ダメ 118.4」）。行をクリックすると、スライダーとマップがその時刻に移動します。

10ストームの中にいた時間帯

ストームに入った時刻・出た時刻・その間に受けたダメージです。

振り返りに使うには

  • 負けた撃ち合いを探す：出来事で「被ダメ」が大きい行をクリック → マップでその場所と前後の動きを確認 → リプレイでその時刻を見る。
  • ストームの使い方を見直す：ストームの表で長く入っていた時間帯を確認 → 「Phase n 収縮」を選んで、次の安地（点線）に対してどう動いていたかを見る。
  • 上位の選手と比べる：同じフェーズで上位の選手を選び、ルートや撃ち合いの場所を比べる。

数字についての注意

  • 推定順位は倒された時刻からの推定で、公式の順位と違うことがあります。
  • 与ダメ・被ダメはプレイヤー同士のダメージだけです（NPC・建築物・ストーム・落下は含みません）。ダウン中の相手への攻撃や死体撃ちは数えていません。
  • ストームダメージは「ストームにいた秒数 × その時のダメージ量」で計算した推定値です。
  • 時刻はリプレイの再生時間です。リプレイで同じ時刻を開くと、その場面を確認できます。
  • フェーズの番号は1から数えています。
  • 止まっている間（建築の中で籠っているときなど）は位置の記録が増えないので、ルートの線は途切れずにつながって見えます。
